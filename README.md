Hash vector suite — rounds in, job id out.

## Features

- Algorithm tag multi
- C++20, CMake 3.20, no third-party fetch
- Job blob + nonce scan + share counter

## Prerequisites

- CMake 3.20+
- A C++20 compiler
- Git

## Getting Started

```bash
git clone <repo-url>
cd hash-vectors
cmake -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

## Project Structure

